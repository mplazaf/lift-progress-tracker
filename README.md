# Lift Progress Tracker

A continuación se detalla información sobre dependencias, arquitectura y levantamiento del proyecto.

## Stack tecnológico

El proyecto utiliza un backend desarrollado con Express y TypeScript, ejecutado sobre Node.js.

La aplicación se encuentra contenerizada mediante Docker y Docker Compose. PostgreSQL se utiliza como sistema gestor de base de datos relacional.

### 🖥️ Tecnologías principales

- **Node.js**: entorno de ejecución para JavaScript.
- **Express**: framework para el desarrollo de la API REST.
- **TypeScript**: lenguaje utilizado para agregar tipado estático.
- **PostgreSQL**: base de datos relacional.
- **Docker**: contenerización de la aplicación.
- **Docker Compose**: orquestación de los servicios del proyecto.
